# ร่องรอย (Remnant)

เกมเดินสำรวจสามมิติบนเว็บ · เอเลี่ยนปลาหมึกในโหลแก้วบนชุดอวกาศ 4 แขน ลงมาสำรวจโลกหลังมนุษย์ล่มสลาย

- เล่นบนคอม คีย์บอร์ดกับเมาส์
- โลกหลังมนุษย์หายไปราวพันปี แมพ 3 × 3 กิโลเมตร (รอบสอง ทำถึงช่วง 12 จาก 14 · ช่วง 12 ยังไม่ได้ดูในโครมทุกข้อ) · รุ่น 0.2.0
- ภูเขาสูงมีหิมะ ป่า 5 แบบ ต้นไม้ 19 ชนิด พุ่มไม้ 6 ชนิด ทุ่งหญ้าสูงกับดอกไม้ 13 ชนิด แม่น้ำมีปลา ทะเลสาบ
- ต้นไม้มีโคนบานกับรากแผ่ ต้นใหญ่รากหนา ยางนามีรากค้ำยัน · พื้นป่ามีเศษใบไม้ร่วง ป่าสนเป็นใบเข็ม
- ภูเขายอดตัด 205 ลูกทั่วแมพ หน้าผาจริง ขอบบนมน ผนังหินเป็นชั้น ลาดหินร่วงที่ตีนผา (เดินปีนลาดได้ ผนังต้องใช้ที่ปีน) · แต่ละลูกเป็นหินทราย หินปูน หินแกรนิต หรือหินดินดาน หน้าตาไม่ซ้ำกัน
- เมืองเก่าที่ป่ากลืน เดินเข้าได้ทุกตึก · หมู่บ้านกลางป่า ทางรถไฟร้าง หอดูไฟป่า และซากอื่นในป่า
- ถ้ำหินปูน (หินย้อย หลุมยุบมีลำแสง แอ่งน้ำมีปลาไม่มีตา ค้างคาว) กับถ้ำเหมืองเก่า (ค้ำยันไม้ ราง รถเข็นแร่ ค่ายพัก)
- แสงอาทิตย์ขึ้นตก หมอกเช้าในหุบ ฝนตก ฟ้าร้อง
- ระบบนิเวศ สัตว์ 14 ชนิดอยู่ตามถิ่นและตามเวลา · หมาป่าเป็นฝูงล่ากวาง ซากมีอีกามากิน หมีกินลูกไม้และจับปลาที่น้ำตก สัตว์ลงกินน้ำ ฝนตกสัตว์หลบ · ฝูงนกกิ้งโครง ผีเสื้อ ผึ้ง กระรอก กบ · ทุกชนิดในโลกสแกนได้ คอลเลกชัน 88 ชนิด
- สแกน: จุดเล็งกลางจอตอนถือเครื่องสแกน ลำแสงจากมือ กรอบไฮไลต์รอบของที่เล็ง สแกนถึง 100% แล้วหยุด · คอลเลกชันหมุนดูโมเดลได้ทุกชนิด ล้อเมาส์ซูม กดขยายเต็มหน้าต่าง
- พิกัด X Y ใต้มินิแมพ กับพิกัดตรงเมาส์บนแผนที่ใหญ่ (ไว้บอกตำแหน่ง · ปิดได้ในหน้าตั้งค่า)
- กลางวันกลางคืน ดวงจันทร์ข้างขึ้นข้างแรม · เสียงธรรมชาติสังเคราะห์ในเบราว์เซอร์
- สองภาษา ไทย และ English เปลี่ยนได้ในหน้าตั้งค่า (จอเดียวมีภาษาเดียวเสมอ)
- ความคืบหน้าบันทึกในเบราว์เซอร์เครื่องนั้นอัตโนมัติ ทุก 15 วินาที ตอนเข้ายาน และตอนปิดแท็บ

```bash
npm install
npm run dev
```
เปิด http://localhost:3700
