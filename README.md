# ร่องรอย (Remnant)

เกมเดินสำรวจสามมิติบนเว็บ · เอเลี่ยนปลาหมึกในโหลแก้วบนชุดอวกาศ 4 แขน ลงมาสำรวจโลกหลังมนุษย์ล่มสลาย

- เล่นบนคอม คีย์บอร์ดกับเมาส์
- เดโม แมพ 1 × 1 กิโลเมตร

```bash
npm install
npm run dev
```
เปิด http://localhost:3700
