## - [x] 3 · ✅ แป้นพิมพ์เด้งขึ้นมาบังปุ่มยืนยัน — ต้องกัน 3 ชั้น

> ✅ **ปิดแล้ว 9 ก.ย. 2569** — **ลงสกิลแล้ว (หัวข้อใหม่ “แป้นพิมพ์บนมือถือ”) · แก้เว็บแล้ว**

**เทคนิค** — ชั้นที่ 1 `interactiveWidget: 'resizes-content'` ใน viewport · ชั้นที่ 2 วัดความสูงแป้นเองแล้วส่งเป็นตัวแปร CSS

```js
const gap = Math.max(0, innerHeight - vv.height - vv.offsetTop);
document.documentElement.style.setProperty('--kb', Math.round(gap) + 'px');
```

ชั้นที่ 3 ป๊อปดันตัวเองขึ้น `transform: translateY(calc(var(--kb) * -1))`

**เหตุผลจากคอมเมนต์** — *"บาง iOS ไม่หดพื้นที่ให้แม้ตั้ง `interactiveWidget` แล้ว"*

**พูดง่าย ๆ คือ** กดช่องกรอกในป๊อปที่ตรึงขอบล่าง แป้นพิมพ์เด้งขึ้นมาทับปุ่มยืนยันจนกดไม่ได้

🚨 ต้องมี `:root { --kb: 0px }` ตั้งไว้ก่อน ไม่งั้น `calc(var(--kb) * -1)` พังทั้งบรรทัดตอนยังไม่มีแป้นพิมพ์

**ลงที่ไหน** — `mobile-web-app` หัวข้อใหม่ "แป้นพิมพ์บนมือถือ" (สกิลไม่มีเรื่องนี้เลย)
