# เช็คลิสต์เว็บใหม่ — ทำตั้งแต่วันแรก

> 🗺️ เปิดคู่กับ — **ทุกสกิลในตารางข้อ 0.0 ของ `working-with-gun`** เพราะเว็บใหม่แตะทุกเรื่อง

> **ตั้งขึ้น 5 กันยายน 2569 ตามที่พี่กันสั่ง**
> *"ควรเป็นข้อที่สำคัญต่อเว็บมาก ๆ ต่อระบบมาก ๆ **และดีสุดคือ เราจะไม่ต้องบอกเธอทุกครั้งที่สร้างเว็บใหม่**"*

**เกณฑ์ที่ของจะเข้ามาอยู่ในไฟล์นี้ได้** — ต้องตอบว่าใช่ทั้งสองข้อ

1. ถ้าไม่ทำตอนเริ่ม **แก้ทีหลังแพง** (ต้องย้ายข้อมูล · รื้อทั้งเว็บ · หรือข้อมูลที่เสียไปแล้วกู้ไม่ได้)
2. **พี่กันต้องสั่งซ้ำทุกเว็บ** ถ้าไม่มีไฟล์นี้

ไฟล์นี้เป็น **รายการติ๊ก** ไม่ใช่ที่เก็บรายละเอียด — รายละเอียดอยู่ในสกิลที่ชี้ไว้ท้ายแต่ละข้อ

---

## 🗄 ฐานข้อมูล — ข้อที่แก้ทีหลังต้องย้ายข้อมูล

- [ ] **ชื่อตารางมีคำนำหน้าของเว็บนี้** (`mr_` · `dm_` · `wb_`) — ฐานเดียวใช้หลายเว็บ ชนกันแล้วแยกไม่ออก
- [ ] **ทุกแถวมีช่องที่สืบกลับได้ตั้งแต่แถวแรก** — ใครบันทึก · เมื่อไหร่ · แก้ครั้งล่าสุดเมื่อไหร่
      **เพิ่มทีหลังคือการย้ายข้อมูลทั้งตาราง** และแถวเก่าจะไม่มีข้อมูลนี้ตลอดไป
- [ ] **ผู้บันทึกติดอัตโนมัติ ผู้ใช้แก้เองไม่ได้** — ชื่อ · วิชาชีพ · เวลา
- [ ] **ร่องรอยการแก้ทำที่ฐาน ไม่ใช่ที่แอป** — ตารางบันทึกการแก้ + ตัวดักที่ฐาน
      **เพราะแก้ตรงในหน้าจัดการฐานก็ต้องถูกจับได้** ถ้าดักที่แอปจะจับไม่ได้เลย
- [ ] **ถังขยะตั้งแต่วันแรก** — ลบ = ประทับเวลา ไม่ลบแถวจริง · ทุกคำสั่งอ่านต้องกรองออก
- [ ] **แช่ค่าที่ใช้คิดเงิน/สถิติไว้ในแถว** — ราคาเปลี่ยนแล้วตัวเลขย้อนหลังต้องไม่ขยับ

📖 รายละเอียด: `pharmacy-web-logic` ข้อ 1 · 9 · 19

## 🔒 ความปลอดภัย — ข้อที่พลาดแล้วข้อมูลหลุดถาวร

- [ ] **กุญแจฐานอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น** ห้ามมีตัวแปรที่เบราว์เซอร์เห็น
- [ ] **กติกาของตารางปิดสิทธิ์เขียนของกุญแจสาธารณะ** — ประตูหน้าเว็บไม่ได้ปิดฐาน ต้องปิดสองชั้น
- [ ] **เว็บที่มีข้อมูลผู้ป่วยต้องมีประตูรหัสผ่าน** และไม่ได้ตั้งรหัส = เว็บต้องตอบ 503 ทั้งเว็บ
- [ ] **ไม่มีอะไรที่เป็นความลับอยู่ในโฟลเดอร์สาธารณะ** — มอคอัป · ไฟล์ทดสอบ · ไฟล์สำรอง
      ทุกอย่างในนั้นคนนอกโหลดได้โดยไม่ผ่านหน้าล็อกอิน
- [ ] **ก่อนเปิดบันทึกของเซิร์ฟเวอร์ ต้องไล่ดูก่อนว่าจะมีข้อมูลระบุตัวคนหลุดลงบันทึกไหม**
- [ ] **`.gitignore` กันไฟล์ตัวแปรลับ ตั้งแต่ commit แรก**

📖 รายละเอียด: `db-safety` · `medical-data-safety`

## 🌐 เน็ตโรงพยาบาลไม่นิ่ง — ต้องออกแบบตั้งแต่แรก

- [ ] **กันบันทึกซ้ำด้วยรหัสก้อนการบันทึก** — เน็ตหลุดตอนส่งแล้วผู้ใช้กดใหม่ ต้องไม่ได้ข้อมูลสองชุด
- [ ] **ตัวสร้างรหัสมีตัวสำรอง** ไม่พึ่งของที่มีเฉพาะ https
- [ ] **ทุกคำขอมีตัวจับเวลาตัด** — เน็ตแบบต่ออยู่แต่ไม่ไปไหนทำให้ปุ่มค้างตลอดกาล
- [ ] **ของที่กรอกค้างเก็บในเครื่อง และลองส่งเองเป็นระยะจนสำเร็จ**

📖 รายละเอียด: `pharmacy-web-logic` ข้อ 20 · 21 · 30

## 🖥 หน้าจอ — ของที่ต้องตั้งฐานให้ถูกตั้งแต่ไฟล์แรก

- [ ] **ฟอนต์ 2 ตัวเป็นฐาน** — Sarabun สำหรับไทย · Roboto Mono สำหรับอังกฤษและตัวเลข
      **เว็บใหม่ตั้งแต่วันแรกเลย** เว็บเก่าห้ามแตะเองต้องรอพี่กันสั่ง
- [ ] 🚨🔴 **ฟอนต์ต้องฝังมากับเว็บ ห้ามลิงก์ไปโหลดจากข้างนอก**
      `next/font/google` ดาวน์โหลดตอนสร้างเว็บแล้วเสิร์ฟจากโดเมนตัวเอง
      **เน็ตโรงพยาบาลบล็อกแหล่งฟอนต์ข้างนอกได้** ตัวหนังสือจะกระพริบหรือกลายเป็นฟอนต์ระบบ
      แล้ว**วรรณยุกต์ไทยที่อุตส่าห์ปรับความสูงบรรทัดมาทั้งเว็บก็เพี้ยนหมด**
      ผลพลอยได้: ไม่ต้องเปิดช่องให้โดเมนข้างนอกในกฎความปลอดภัยของหน้าเว็บ
- [ ] 🦴🔴 **เปลี่ยนหน้าแล้วต้องอยู่บนสุดเสมอ** — ใส่ที่โครงเว็บจุดเดียวตั้งแต่ไฟล์แรก (`web-craft` 6.26)
  เทสบนจอเตี้ย เลื่อนลง 40 · 100 · 250 แล้วกดเข้าหน้าอื่น ต้องได้ 0 ทุกครั้ง · จอใหญ่บังเอิญผ่าน ห้ามเทสแค่จอใหญ่
- [ ] **จองที่ให้แถบเลื่อนเสมอ** (`scrollbar-gutter: stable`) ไม่งั้นหน้าขยับตอนเนื้อหายาวขึ้น
- [ ] **ตารางต้องเป็นตารางจริง** ไม่ใช่กล่องเรียงกันให้ดูเหมือนตาราง
- [ ] **หน้าที่รอข้อมูลต้องมีโครงจางรูปร่างเหมือนของจริง**
- [ ] **ปุ่มทุกปุ่มตอบสนองตอนเอาเมาส์ชี้ และกดด้วยคีย์บอร์ดได้**
- [ ] **"โหลดไม่สำเร็จ" ต้องหน้าตาต่างจาก "ไม่มีข้อมูล"** — หน้าที่รายงานตัวเลขห้ามวาดตัวเลขเลยตอนโหลดไม่สำเร็จ
- [ ] **วันที่บนจอเป็น พ.ศ. และวันที่ส่งมาจากเบราว์เซอร์** ไม่ใช่นาฬิกาของฐาน

📖 รายละเอียด: `web-craft` · `button-feedback` · `loading-skeleton`

## 📝 ฟอร์ม — ของที่ทำให้ข้อมูลหายเงียบ ๆ

- [ ] **ช่องเลือกเริ่มที่ค่าว่างเสมอ** ค้างค่าแรกไว้ = บันทึกค่าที่ไม่ได้ตั้งใจ
- [ ] **ค่าว่างแปลงเป็นค่าว่างจริงของฐานก่อนส่ง** ไม่งั้นฐานตีกลับแล้วบันทึกไม่เข้าแบบเงียบ ๆ
- [ ] **หน้าแก้ไขใช้ตัวควบคุมชนิดเดียวกับหน้ากรอก** และมีช่องครบเท่ากัน
- [ ] **ทำความสะอาดข้อความที่ประตูเดียว ตอนรับเข้า** ไม่ใช่ไล่แก้ตอนแสดงผลทีละหน้า

📖 รายละเอียด: `form-input`

## 📤 ส่งออกและพิมพ์

- [ ] **ไฟล์ตารางต้องมีเครื่องหมายนำหน้าไฟล์** ไม่งั้นเปิดในโปรแกรมตารางแล้วภาษาไทยเพี้ยน
- [ ] **กันสูตรฝังในไฟล์ส่งออก** — ช่องที่ขึ้นต้นด้วย `= + - @` ต้องเติมเครื่องหมายนำหน้า
- [ ] **ใบพิมพ์เอกสารราชการใช้ฟอนต์ราชการ ห้ามให้ฟอนต์เว็บลามเข้าไป**
- [ ] **ตัดข้อมูลส่วนบุคคลออกอัตโนมัติตอนส่งออก**

📖 รายละเอียด: `making-documents` · `medical-data-safety`

## 🚀 ปล่อยขึ้นเว็บจริง

- [ ] **ชื่อในไฟล์ตั้งค่าตรงกับชื่อบนบริการที่ใช้เป๊ะ** ไม่ตรง = ไปสร้างเว็บใหม่อีกอันแทนที่จะทับของเดิม
- [ ] **ตัวแปรลับตั้งเป็นชนิดความลับ ไม่ใช่ข้อความธรรมดา** และต้อง deploy ใหม่ถึงมีผล
- [ ] **ปิดทางเข้าที่ไม่ผ่านหน้าล็อกอิน** รวมถึงเส้นทางที่ลงท้ายด้วยนามสกุลไฟล์
- [ ] **ไอคอนกับโลโก้ที่มีตัวอักษรพิเศษ ต้องแปลงเป็นเส้นวาด** ไม่งั้นเครื่องที่ไม่มีฟอนต์นั้นเห็นเป็นกล่องเปล่า

📖 รายละเอียด: `db-safety` · `working-with-gun` ข้อ 4.1.6

## 🩺 เว็บที่เกี่ยวกับยาและผู้ป่วย — เพิ่มอีกชุด

- [ ] **ชื่อยาแสดงครบทุกส่วน** ความแรง · รูปแบบ · ER/IR — ห้ามตัดบรรทัด
- [ ] **จับกลุ่มสถิติด้วยรหัสยา ไม่ใช่ชื่อยา**
- [ ] **ค่าที่แสดงผลอย่างเดียว ต้องเขียนแยกจากค่าที่ใช้ตัดสินใจรักษา**
- [ ] **ระบบเตือน ไม่ใช่ระบบห้าม** — และตัวเลือกที่ใกล้กันต้องเขียนเส้นแบ่งกำกับ
- [ ] **ตัวย่อยาเลือกตัวเดียวและใช้ชื่อสากล** ยาตัวเดียวมีหลายตัวย่อ
- [ ] **ห้ามเดาข้อมูลยาแล้วเขียนลงฐานจริง**
