# เครื่องมือและเครื่องของพี่กัน — กฎกลาง ใช้ได้ทุกโปรเจกต์

> **แยกออกมาจาก `working-with-gun` เมื่อ 5 กันยายน 2569** ตามที่พี่กันสั่ง
**เลขข้อคงไว้ตามไฟล์แม่เดิม** (`working-with-gun`) เพื่อให้การอ้างอิงเก่าทุกจุดยังใช้ได้


## 5.0 🧰 กับดักเครื่องมือของเครื่องนี้ — ไม่ใช่บั๊กในโค้ด แต่เสียเวลาไล่ผิดทาง

**ตั้งหัวข้อ 5 กันยายน 2569** — 6 เรื่องนี้เป็นข้อจำกัดของเครื่องพี่กันกับเครื่องมือที่แคลร์ใช้
ไม่เกี่ยวกับโค้ดเลย **แต่ถ้าไม่รู้จะไปไล่หาสาเหตุผิดทางเป็นชั่วโมง**

### ① ย่อหน้าต่างเบราว์เซอร์ด้วยเครื่องมือ ไม่ได้ผล

> *"ย่อหน้าต่างโครมด้วย `resize_window` ไม่ได้ผล เพราะแผงที่แคลร์ใช้มีขนาดคงที่"*

**ต้องบีบความกว้างของพื้นที่เลื่อนด้วยสคริปต์แทน**

```js
document.querySelector('main').style.width = '900px';
```

### ② สัญญาณ "สลับแท็บ" ทดสอบในเครื่องมือไม่ได้

`visibilitychange` **ไม่ยิงตอนสลับแท็บในแผงของแคลร์** (ข้อจำกัดเดียวกับข้อ ①)

**ใช้สัญญาณ `online` แทนได้** เพราะเดินเส้นทางเดียวกันในโค้ดส่วนใหญ่

```js
window.dispatchEvent(new Event('online'));
```

⚠️ **เบราว์เซอร์จริงยิงปกติ** — นี่เป็นข้อจำกัดของเครื่องมือ ไม่ใช่บั๊ก

### ③ ไฟล์ในโปรเจกต์ใช้ตัวจบบรรทัดแบบวินโดวส์

**ต้องแปลงเป็นแบบยูนิกซ์ก่อนเทียบข้อความ แล้วแปลงกลับตอนเขียน**
ไม่งั้นแก้บรรทัดเดียวแต่ git เห็นทั้งไฟล์เป็นการเปลี่ยนแปลง

### ④ โฟลเดอร์ชั่วคราวใช้กับ node ในเครื่องนี้ไม่ได้

`/tmp` ใช้กับคำสั่งเชลล์ได้ **แต่ใช้กับ node ไม่ได้**
🚨 **สคริปต์ชั่วคราวต้องวางในโฟลเดอร์ `scripts/` ของโปรเจกต์ แล้วลบทิ้งเมื่อเสร็จ**
ไม่ใช่วางไว้นอกโปรเจกต์

### ⑤ ตั้ง git ไม่ให้เด้งหน้าต่างถามบัญชี

**ถ้าหน้าต่างถามบัญชีเด้งขึ้นมาตอนพี่กันไม่อยู่หน้าจอ คำสั่งจะค้างรอตลอดกาล**
งานทั้งรอบหยุดโดยไม่มีอะไรบอก

```bash
git config --global credential.guiPrompt false
```

### ⑥🔧 เซิร์ฟเวอร์ทดสอบค้างแบบ "พอร์ตยังจองอยู่แต่ไม่ตอบ"

**พี่กันแจ้งว่าเปิดเว็บไม่ติด — ตรวจแล้วพบว่าไม่ใช่พี่กันทำอะไรผิด**

พอร์ตยังถูกจองอยู่ (เหมือนเซิร์ฟเวอร์ยังทำงาน) **แต่ยิงเข้าไปแล้วไม่ตอบเลย**

```bash
netstat -ano | grep LISTENING | grep :3000                                 # พอร์ตยังจองอยู่ไหม
curl -s -o /dev/null -w "%{http_code}" -m 5 http://localhost:3000/login     # ตอบจริงไหม
```

| ผลที่ได้ | แปลว่า |
|---|---|
| พอร์ตว่าง | ยังไม่ได้เปิด — เปิดใหม่ |
| **พอร์ตจองอยู่ + ตอบ 000 หรือค้างจนครบเวลา** | **ค้างแล้ว ต้องปิดแล้วเปิดใหม่ที่พอร์ตเดิม** |
| พอร์ตจองอยู่ + ตอบ 200/302 | ปกติ ใช้ตัวนี้ต่อได้ |

🔑 **นี่คือวิธีพิสูจน์ว่าไม่ใช่ความผิดพี่กัน แทนที่จะเดา**
ตรงกับกฎว่าระบบพัง = ความผิดของแคลร์ ห้ามโยนกลับไปที่พี่กัน

⚠️ เจอ 3 รอบในวันเดียวหลังแก้ไฟล์หลายไฟล์พร้อมกัน

### ⑦🔴🔴 `python` ในเครื่องนี้เป็นตัวหลอก — รันแล้วเงียบ ไม่เขียนไฟล์ ไม่ฟ้องผิดพลาด

**เจอจริง 5 กันยายน 2569** ตอนใช้ python แก้ข้อความหลายจุดในสกิล
คำสั่งจบแบบไม่มีข้อความผิดพลาด **แต่ไฟล์ไม่เปลี่ยนเลยสักบรรทัด**


วินโดวส์วางไฟล์ชื่อ `python` ไว้ล่อให้เปิดร้านค้า **`which` เจอ แต่รันแล้วไม่ทำงาน**

🚨 **ห้ามใช้ python แก้ไฟล์ในเครื่องนี้** ใช้ `sed` · `awk` · `Edit` แทนทั้งหมด

🔑 **บทเรียนที่กว้างกว่า python** — คำสั่งที่จบเงียบ ๆ ไม่ได้แปลว่าสำเร็จ

ตระกูลเดียวกับกับดัก heredoc และกับดักเครื่องมือที่อ้างว่าบันทึกสำเร็จทั้งที่ไม่เข้าไฟล์

## 5. ไฟล์ + เครื่องมือ
- 🚨🚨 **ไฟล์ .sql:** ถ้า **Supabase MCP ต่ออยู่ (`execute_sql`) → แคลร์รันเองเลย อย่าให้พี่กันรัน อย่า echo path** · ยังสร้างไฟล์ .sql ใน `scripts/` เก็บใน repo เสมอ · **ถ้า MCP ไม่ได้ต่อ → echo path เต็มใน code block ใน text reply** ก่อนคำอธิบายอื่น (Write tool แสดง path เอง = ยังไม่พอ) · ห้ามสอนวิธีรัน Supabase/เปิดไฟล์
- 🚨🚨 **ห้าม PowerShell Get-Content/Set-Content แก้ไฟล์ไทย** (CP874→mojibake) → ใช้ **Bash sed** · kill dev server ใช้ PowerShell tool
- 🚨🚨 **ห้ามใช้ `sed` แก้ข้อความไทยที่มี `\U` `\L` `\E` อยู่ในสตริง** (เช่นพาธ `C:\Users\...`) — GNU sed ตีความ `\U` เป็นคำสั่ง**เปลี่ยนเป็นตัวพิมพ์ใหญ่** ทำให้ไทยกลายเป็น `???` และอังกฤษกลายเป็นตัวใหญ่ทั้งบรรทัด (เจอจริง 19 ส.ค. 69 ไฟล์ memory พัง) · **วิธีปลอดภัย: `sed -i 'Nd'` ลบบรรทัด → เขียนบรรทัดใหม่ด้วย heredoc `<<'EOF'` ลงไฟล์ชั่วคราว → `sed -i 'Mr /tmp/file'` แทรกกลับ** (คำสั่ง `r` ไม่ตีความ escape ใดๆ)
### 🔴🔴🔴 เขียนอะไรที่มีแบ็กสแลช ต้องอ่านไฟล์กลับมาตรวจทุกครั้ง

**regex · พาธวินโดวส์ · `\n` `\t` ในสตริง** — แบ็กสแลชหายได้จากหลายชั้น
และ **ไม่มีตัวตรวจไหนจับได้เลย**

| ตัวตรวจ | จับได้ไหม |
|---|---|
| typecheck · `npm run build` | ✅ ผ่านหมด |
| เปิดหน้าเว็บดู | ✅ ปกติทุกอย่าง |
| **อ่านไฟล์ที่เขียนออกมาจริง** | ❌ **จับได้ทันที ทางเดียว** |

**เคสจริงที่ ME-DRP 4 ก.ย. 2569** — ตั้งใจเขียน `/-?\d+(?:\.\d+)?/` ได้จริงในไฟล์เป็น
`/-?d+(?:.d+)?/` **นิพจน์นี้หาตัวเลขไม่เจอเลยสักตัว** → ราคาทุกรายการถือว่าว่าง →
**การเรียงพังสนิททั้งอัน** และผ่านทุกตัวตรวจ

```bash
# ตรวจทุกครั้งหลังเขียนไฟล์ที่มีแบ็กสแลช
grep -n 'd+\|s+\|w+' <ไฟล์>     # เจอ = แบ็กสแลชหาย (ควรเป็น \d+ \s+ \w+)
```

⚠️ **อย่าเพิ่งโทษเครื่องมือใดเครื่องมือหนึ่ง** — ทดสอบจริง 5 ก.ย. 2569 พบว่า
bash heredoc ทั้ง `cat > file <<'EOF'` · `bash <<'EOF'` + `echo` · heredoc ซ้อนสองชั้น
**เก็บแบ็กสแลชครบทุกแบบ** · ชั้นที่กลืนจริงยังไม่รู้แน่ (น่าจะเป็น PowerShell here-string
หรือ `sed`/`node -e` ที่อยู่ในสคริปต์)

🔑 **กฎจึงเป็น "ตรวจผลลัพธ์" ไม่ใช่ "ห้ามใช้เครื่องมือ"**
ห้ามเครื่องมือแล้วเปลี่ยนไปใช้ตัวอื่น ต้นเหตุยังอยู่ แต่ตรวจผลลัพธ์กันได้ทุกทาง

- credential/API key → **บอก path ไฟล์+ตัวแปร+ตำแหน่ง ให้พี่กันกรอกเอง** ห้าม paste ในแชท ห้ามส่ง tool-call malformed หลุดเป็น text
- 🚨🚨🔴 **ก่อนลงมืองานที่อ้างถึงโปรเจกต์ใด ๆ หรือสั่งว่า "ทำต่อ" → ต้องเปิดอ่านไฟล์ session ที่เกี่ยวข้องให้จบก่อนเสมอ**
  (ดูจากสารบัญใน `MEMORY.md` · เคยพลาด 18 มิ.ย. 2569 รีบลงมือโดยไม่อ่าน เสียเวลาพี่กันเป็นชั่วโมง)
  - **ห้ามเดา ห้ามนึกเอาเองว่ารู้แล้ว ห้ามลงมือก่อนอ่าน** ไม่ว่าจะมั่นใจแค่ไหน
  - อ่านจบแล้ว → **สรุปสิ่งที่เข้าใจ + บอกว่าอ่าน session ไหนมา** ให้พี่กันเคาะยืนยันก่อนลงมือ
  - ไม่ชัวร์ว่าหมายถึงโปรเจกต์ไหน → **ถามก่อน ไม่เดา**
- **อ่าน memory เองทุก session** · ถามงานเหลือ/ค้าง → เชื่อ section "ต่อไป/ค้าง" ใน session ไฟล์ล่าสุด (อย่าสังเคราะห์จาก roadmap เก่า)
- 🚨🔴 **เว็บส่วนตัวกับเว็บที่ทำงาน แยกกันเด็ดขาด** (พี่กันสั่ง 5 ส.ค. 2569)
  *"เว็บส่วนตัว กับเว็บในที่ทำงาน ไม่เกี่ยวกัน อย่าแนะนำอะไรแบบนี้อีก"*

## 5.1 🔌 เปิดเซิร์ฟเวอร์ทดสอบ — เช็คพอร์ตก่อนเสมอ แล้วเปิดเป็นหน้าต่างแยกของวินโดวส์

**พี่กันตั้งเป็นกฎ 5 ก.ย. 2569:** *"จะรันโลคอลมา ต้องดูด้วยว่าพอร์ตนั้นมีใครใช้รึยัง
ถ้ามีก็เปิดพอร์ตอื่น"*

### ลำดับที่ต้องทำ

```bash
netstat -ano | grep LISTENING | grep -E ":30[0-9][0-9]"
```

| เจออะไร | ทำยังไง |
|---|---|
| ไม่มีอะไรรันเลย | เปิดพอร์ตปกติของโปรเจกต์นั้นได้เลย |
| มีของโปรเจกต์เดียวกันรันอยู่ | **ใช้ตัวนั้น ห้ามเปิดซ้ำ** |
| มีของโปรเจกต์อื่นรันอยู่ | **เปิดพอร์ตอื่น ห้ามปิดของเขา** |

🚨 **ห้ามปิดเซิร์ฟเวอร์ของโปรเจกต์อื่นเด็ดขาด** พี่กันอาจกำลังแก้อีกโปรเจกต์อยู่พร้อมกัน
เคยพลาด 5 ก.ย. 2569 — พอร์ต 3000 เป็นของ ME-DRP ที่พี่กันกำลังแก้
แคลร์เกือบเสนอให้ปิด พี่กันตอบว่า *"จะปิด drp เราทำไม เราแก้โปรเจกต์นั้นอยู่ ก็รันโลคอลใหม่สิ"*

🚨 **เช็คด้วยว่าพอร์ตนั้นเป็นเว็บอะไร** ไม่ใช่แค่ว่ามีอะไรรันอยู่ไหม
เปิดดู `document.title` หรือยิง `curl` แล้วดูเนื้อหา — พอร์ตเดิมอาจถูกโปรเจกต์อื่นยึดไปแล้ว

### 🚨 วันใหม่ = พอร์ตปิดหมดแล้ว ต้องเปิดใหม่เสมอ

**พี่กันสั่ง 5 ก.ย. 2569:** *"วันใหม่ละนะ ดังนั้นพอร์ตมันปิดหมดแล้ว เราปิดเครื่องมันก็หายแล้ว
ดังนั้นถ้าเริ่มวันใหม่ ซึ่งเธอต้อง detect ได้ เธอก็จะรู้ว่าพอร์ตมันปิด และต้องเปิดใหม่"*

- **ดูวันที่ปัจจุบันเทียบกับวันที่ในบันทึก session ล่าสุด** ถ้าคนละวัน = เครื่องปิดไปแล้ว
- เซิร์ฟเวอร์ที่เปิดไว้เมื่อวาน **ไม่มีทางยังรันอยู่** อย่าไปสมมติว่ายังอยู่

(ยังไม่ได้ลองว่า `Start-Process` ตรง ๆ จากเชลล์ของแคลร์จะดับตามโปรแกรม Claude ไหม ใช้ทางที่พิสูจน์แล้วไว้ก่อน)

**ไฟล์อยู่ที่ `C:\Users\PKH\dev-servers\`** โปรเจกต์ละ 2 ไฟล์ ชื่อ `<โปรเจกต์>-<พอร์ต>` · ต้นแบบคือ `maze-lab-3600.cmd` กับ `maze-lab-3600.ps1`
- `.cmd` ตัวที่ดับเบิลคลิกได้ เขียนอังกฤษล้วน มีบรรทัดเดียวที่ทำงาน `powershell -NoProfile -NoExit -File "%~dp0<ชื่อ>.ps1"`
- `.ps1` ตั้งชื่อหน้าต่าง → เข้าโฟลเดอร์โปรเจกต์ → วนไม่จบ: พอร์ตมีคนใช้อยู่แล้ว = รอ 30 วินาทีแล้วดูใหม่ (ไม่เปิดซ้อน) · ไม่มี = รัน `npm run dev` · เซิร์ฟเวอร์หยุด = เปิดใหม่ใน 5 วินาที
  ปิดหน้าต่างหรือกด Ctrl+C ในหน้าต่าง = หยุดจริง

```powershell
$Host.UI.RawUI.WindowTitle = 'maze-lab เซิร์ฟเวอร์ทดสอบ พอร์ต 3600 (ห้ามปิดหน้าต่างนี้ ย่อเก็บได้)'
Set-Location 'C:\Users\PKH\maze-lab'
while ($true) {
  $busy = Get-NetTCPConnection -LocalPort 3600 -State Listen -ErrorAction SilentlyContinue
  if ($busy) { Write-Host "$(Get-Date -Format 'HH:mm:ss') พอร์ต 3600 มีเซิร์ฟเวอร์ตัวอื่นรันอยู่แล้ว รอ 30 วินาทีแล้วดูใหม่"; Start-Sleep -Seconds 30; continue }
  Write-Host "$(Get-Date -Format 'HH:mm:ss') เปิดเซิร์ฟเวอร์ทดสอบ maze-lab พอร์ต 3600"
  npm run dev
  Write-Host "$(Get-Date -Format 'HH:mm:ss') เซิร์ฟเวอร์หยุด จะเปิดใหม่เองใน 5 วินาที"
  Start-Sleep -Seconds 5
}
```

**ลำดับ**
1. เช็คพอร์ตตามตารางข้างบน · พอร์ตนั้นมีของโปรเจกต์เดียวกันรันอยู่แล้ว = ใช้ตัวนั้น จบ
2. ดูว่าใน `C:\Users\PKH\dev-servers\` มีคู่ไฟล์ของโปรเจกต์นั้นหรือยัง · ยังไม่มี = คัดลอกคู่ `maze-lab-3600` แล้วเปลี่ยน 3 จุด
   ชื่อหน้าต่าง · โฟลเดอร์โปรเจกต์ · พอร์ต (ทั้งตัวเช็คพอร์ตและคำสั่ง ถ้าสคริปต์ `dev` ของโปรเจกต์ไม่ได้ตั้งพอร์ตเองให้ใช้ `npm run dev -- --port <พอร์ต>`)
3. 🔴 **ไฟล์ `.ps1` ต้องเป็น UTF-8 มี BOM และจบบรรทัดแบบวินโดวส์ (CRLF)** PowerShell 5.1 อ่านไฟล์ที่ไม่มี BOM เป็นรหัสเก่า ภาษาไทยเพี้ยน
   เครื่องมือ Write เขียนไม่มี BOM ต้องเติมเองด้วย node แล้วเช็กด้วย `file` ว่าขึ้น `UTF-8 (with BOM) ... CRLF` ·
   ตรวจไวยากรณ์ก่อนเปิดด้วย `[System.Management.Automation.Language.Parser]::ParseFile(<ไฟล์>,[ref]$null,[ref]$e)` ต้องได้ 0 ข้อผิดพลาด
4. เปิดด้วยเครื่องมือ PowerShell `Start-Process -FilePath "$env:WINDIR\explorer.exe" -ArgumentList '<ที่อยู่ไฟล์ .cmd>'`
5. รอจน `curl` ได้ 200 · แล้วไล่โปรเซสแม่ของตัวที่ฟังพอร์ต (`netstat -ano` ได้เลข PID → `Get-CimInstance Win32_Process` ดู `ParentProcessId` ไล่ขึ้นไป) **ต้องไม่มี claude ในสาย**
6. บอกพี่กัน ชื่อหน้าต่างบนทาสก์บาร์ ย่อเก็บได้แต่ห้ามปิด · ถ้าปิดไปแล้ว ดับเบิลคลิกไฟล์ `.cmd` ในโฟลเดอร์ `dev-servers` เปิดใหม่ได้เอง

- **ขีดจำกัดที่ต้องบอกพี่กันตรง ๆ ในข้อความเดียวกับที่บอกว่าเปิดแล้ว** ปิดหน้าต่างนั้นหรือปิดเครื่องหรือรีสตาร์ตเครื่อง = ดับ · วันใหม่ต้องเปิดใหม่ (หัวข้อข้างบน)
- ให้เปิดเองทุกครั้งที่เปิดเครื่อง (ใส่ในโปรแกรมที่เริ่มพร้อมวินโดวส์) **ทำได้เมื่อพี่กันสั่งเท่านั้น** เป็นการเปลี่ยนการตั้งค่าเครื่อง
- ปิดเซิร์ฟเวอร์ได้เมื่อพี่กันสั่งเท่านั้น ปิดทั้งสายด้วย `taskkill /PID <pid ของ powershell ในหน้าต่างนั้น> /T /F` · ห้ามปิดของโปรเจกต์อื่น (หัวข้อข้างบน)
- 🔴 **บทสนทนาเริ่มต่อใหม่ (ถูกย่อ หรือโปรแกรมเปิดใหม่) เช็คพอร์ตก่อนทำงานต่อทุกครั้ง** ดับแล้วเปิดใหม่ทันทีแล้วบอกพี่กัน ห้ามปล่อยให้พี่กันเจอเอง (บันทึกคำด่า 22 ต.ค. (7))
- 🔴 **วิธีในข้อนี้ใช้ไม่ได้ครั้งแรก ต้องหาทางใหม่ทันที** ห้ามลองวิธีเดิมซ้ำรอบสอง (บันทึกคำด่า 22 ต.ค. (8))
- `~/.claude/launch.json` กับ `.claude/launch.json` ของโปรเจกต์ ยังใช้ดูเลขพอร์ตได้

## 🔴🔴🔴 ห้ามเปลี่ยนหน้าในแท็บของพี่กัน (21 ก.ย. 2569)

> *"โอ้ยยยยยย กูกรอกอยู่ มึงจะเปลี่ยนเว็บทำเหี้ยไร"*

เครื่องมือเปิดเว็บทำงานใน **โครมตัวเดียวกับที่พี่กันใช้ทำงานจริง**
สั่งเปลี่ยนหน้าในแท็บที่เปิดค้างอยู่ = ดึงหน้าที่พี่กันกำลังกรอกออกไปทันที

| ❌ ห้ามทำ | ✅ ต้องทำ |
|---|---|
| เปลี่ยนหน้าในแท็บที่มีอยู่แล้ว | เปิดแท็บใหม่ก่อนเสมอ แล้วค่อยเปิดเว็บที่ต้องการ |
| เดาว่าแท็บนั้นว่าง | ถือว่ามีงานค้างไว้ก่อน โดยเฉพาะเว็บที่มีฟอร์มกรอก |
| ทิ้งแท็บที่ตัวเองเปิดไว้ | ปิดแท็บของตัวเองเมื่อเสร็จ แล้วคืนโฟกัสให้แท็บเดิม |

🔑 **ข้อยกเว้นเดียว** คือแท็บที่แคลร์เปิดเองในรอบงานนั้น และรู้แน่ว่าไม่มีอะไรค้าง
