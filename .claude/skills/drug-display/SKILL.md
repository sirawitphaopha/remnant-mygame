### 🚨 โหมดมืดต้องมีชุดสีของตัวเอง — ไม่งั้นชื่อยาหายทั้งบรรทัด

**เจอจริงที่เว็บยาคืน** การ์ด "ยาที่คืนมูลค่าสูงสุด 10 อันดับ" ในหน้าสรุปโหมดมืด
**เห็นแต่ความแรงกับรูปแบบยา ชื่อสามัญหายไปทั้งบรรทัด** เพราะสีเกือบดำกลืนพื้นมืด

```js
const C = (dark) => ({
  name:     dark ? '#e8ece9' : '#1e2420',
  form:     dark ? '#b9c2bc' : '#414a44',
  strength: dark ? '#9aa5a0' : '#6b746e',
  hitBg:    dark ? 'rgba(47,125,93,.32)' : '#dcefe4',
  hitFg:    dark ? '#7fd6ab' : '#2f7d5d',
  brand:    dark ? '#7fd6ab' : '#2f7d5d'
});
```

🚨 **เปลี่ยนเฉพาะสีที่เข้มจนกลืนพื้นมืด** — ม่วง (ตัวย่อ) · ส้ม (%) · แดงอมชมพู (ER/IR)
เป็นสีกลางที่อ่านออกทั้งสองพื้น **ห้ามเปลี่ยน** เพราะแต่ละสีมีความหมายเฉพาะตัว

ถ้าเขียนแยกกันทีละหน้า **ยาตัวเดียวกันจะหน้าตาไม่เหมือนกันในเว็บเดียวกัน**

```js
// components/helpers.js
export function splitRelease(text) {

  if (!m) return { main: text, release: '' };
  return { main: m[1].trim(), release: m[2] };
}
```

## 26. สีความแรง — ยาชื่อเดียวกันหลายความแรงต้องคนละสี 🔴

**พี่กันสั่ง 13 ส.ค. 2569:** *"ยาที่ตัวเดียวกันและคนละความแรงก็ต้องแยกสี"*

### ปัญหา

`Morphine 10 · 20 · 30 mg` หยิบสลับกันแล้ว **อันตรายถึงชีวิต**
ตาต้องจับความต่างได้ตั้งแต่กวาดผ่าน ไม่ใช่ต้องอ่านทีละตัว

### กติกา

- **ทำงานเฉพาะตอนผลค้นหามียาชื่อเดียวกันตั้งแต่ 2 รายการขึ้นไป** — เจอตัวเดียวคงเทาเหมือนเดิม
  (ไม่งั้นทั้งจอเป็นสีรุ้ง สีเลยหมดความหมาย)
- **ทาสีเฉพาะตัวเลข ส่วนหน่วยคงเทาเดิม** — เน้นจุดที่ต่างกันจริง บรรทัดไม่รกไปกว่าเดิม
- จับกลุ่มด้วย **ชื่อยาที่ตัดความแรงออกแล้ว** ไม่ใช่ชื่อเต็ม (ชื่อเต็มมีความแรงติดอยู่)

### ชุดสีที่พี่กันเลือก

```js
const ST_COLORS = ['#0b62d6', '#b04a00', '#00808f', '#5b34c9', '#6b6b52'];
//                 น้ำเงินสด   ส้มอิฐ    เทอร์ควอยซ์  ม่วงคราม   เขียวมะกอก
```

🚨 **ห้ามใช้สีที่จองไว้แล้ว** — เทล (ชื่อการค้า + ไฮไลต์คำค้น) · ม่วง (ตัวย่อ) ·
ส้ม (เปอร์เซ็นต์) · แดงอมชมพู (ER/IR) · แดง (ทำลาย / ยังไม่ใส่ราคา)

**ต้องอ่านออกทั้งบนพื้นขาวและพื้นตอนถูกลูกศรเลือก** (`#eef6f1` ในเว็บยาคืน · `#E4F3F0` ใน ME-DRP)
เลือกสีใหม่เมื่อไหร่ต้องเทสสองสถานะนี้เสมอ

### 🔴🔴 สีเม็ดยาจริงมาก่อนสีที่ระบบสุ่มเสมอ

**พี่กันสั่ง 25 ส.ค. 2569** · **พี่กันทวงซ้ำ 5 ก.ย. 2569** เพราะกฎข้อนี้ไม่เคยถูกจดลงสกิล
อยู่แต่ในคอมเมนต์โค้ดของเว็บยาคืน 2 จุด — คนที่อ่านสกิลอย่างเดียว**ไม่มีทางรู้** แล้วก็ทำขาดจริง ๆ

```js
// 🚨 สีเม็ดยาจริงมาก่อนสีที่ระบบสุ่มให้เสมอ (Warfarin)
const pill = pillColorOf(drug);
const stColor = pill ? pill.color : stColorOf(drug);
```

**เหตุผล** — สีสุ่มจากชุด `ST_COLORS` มีไว้แค่ *"ทำให้ต่างกัน"* ไม่ได้สื่อความหมายอะไรในตัวเอง
แต่**สีเม็ดยาคือของจริงที่อยู่ในมือคนไข้** ผู้ผลิตตั้งใจทำมาให้แยกความแรงด้วยสี

```
Warfarin (ส้ม) 2 mg tab      ← เลข 2 ต้องเป็นสีส้ม
Warfarin (น้ำเงิน) 3 mg tab   ← เลข 3 ต้องเป็นสีน้ำเงิน
Warfarin (ชมพู) 5 mg tab     ← เลข 5 ต้องเป็นสีชมพู
```

🚨 **กฎมี 2 ชั้น ทำชั้นเดียวไม่พอ**
1. ป้ายสีในวงเล็บ `(ส้ม)` — บอกว่าเม็ดสีอะไร
2. **ตัวเลขความแรงทาสีเดียวกัน** — ให้ตาจับคู่ "สี ↔ ความแรง" ได้ทันทีโดยไม่ต้องอ่าน

ทำแค่ชั้นเดียวคือ **สียังไม่ครบ** (พี่กันใช้คำนี้เอง 5 ก.ย. 2569 ตอนจับได้)

🚨 **Warfarin คือยาที่พลาดแล้วเจ็บที่สุดในคลัง** — ได้เกินไปนิดเดียวเลือดออกในสมองได้
น้อยไปก็เกิดลิ่มเลือด · หน้าจอต้องพูดภาษาเดียวกับเม็ดยาที่อยู่ในมือ

🚨 **สีเม็ดยาไม่สนใจกติกา "ต้องมี 2 รายการขึ้นไป"** — สีสุ่มโผล่เฉพาะตอนชื่อซ้ำ
แต่สีเม็ดยาเป็นข้อมูลของยาตัวนั้น **แสดงเสมอแม้เจอตัวเดียว** และแสดงทุกหน้ารวมทั้งหน้าคลังยา

🚨 **หน้าที่แสดงยาทั้งคลังห้ามส่งสีสุ่มเข้าไป** (417 ตัว = สีรุ้งทั้งจอ สีหมดความหมาย)
**แต่สีเม็ดยาจริงยังต้องมา** เพราะไม่ใช่สีตกแต่ง

**แต่สีเม็ดยาตัวกลางหาเองได้** เพราะอยู่ในข้อมูลของยาตัวนั้นเลย

### 🎨 สีเม็ดยามาจากไหน — ฐานข้อมูล ไม่ใช่โค้ด

**คอลัมน์ในตาราง `drugs`** (ตารางกลางที่ใช้ร่วมทุกเว็บ)

| คอลัมน์ | เก็บอะไร |
|---|---|
| `pill_color` | **ชื่อสีภาษาไทย** — `ส้ม` · `น้ำเงิน` · `ชมพู` |
| `pill_color_hex` | รหัสสี · **เว้นว่างได้ ระบบเติมจากชื่อสีให้เอง** |

**ตัวช่วยกลาง `lib/drugPillColors.js`** (49 บรรทัด)

```js
export const COLOR_HEX = { /* แปลงชื่อสีไทย → รหัสสี */ };
export function pillColorOf(drug) { /* คืน {label, color} หรือ null */ }
```

🚨🔴 **ไฟล์นี้ถูกก๊อปไปวางที่ ME-DRP ด้วยแล้ว (`lib/drugPillColors.ts`)
แก้ที่ไหนต้องก๊อปไปอีกที่เสมอ** (กฎเดียวกับ `drugSearch.js`)

🚨 **เก็บในฐานไม่ฝังในโค้ด** — เพิ่มยาตัวใหม่แค่กรอกในหน้าคลังยา ไม่ต้องแก้โค้ดทั้งสามเว็บ

### ตอนนี้ในฐานมีสีเม็ดยาแค่ 3 แถว (ตรวจจริง 5 ก.ย. 2569)

```sql
select generic, strength, form, pill_color, pill_color_hex
from drugs where pill_color is not null and pill_color <> '';
```

| ยา | ความแรง | สี | รหัสสี |
|---|---|---|---|
| Warfarin | 2 mg tab | ส้ม | `#d1610b` |
| Warfarin | 3 mg tab | น้ำเงิน | `#0b62d6` |
| Warfarin | 5 mg tab | ชมพู | `#d6337e` |

**3 แถวจากยาทั้งหมด 418 ตัว** — Warfarin เป็นยาตัวเดียวในคลังที่มีกฎนี้ตอนนี้

⚠️ **ห้ามใส่สีเม็ดยาให้ยาตัวอื่นเอง** ต้องเป็นสีที่พี่กันยืนยันว่าตรงกับเม็ดจริงในคลัง
สีที่เดาเอาเองอันตรายกว่าไม่มีสี เพราะคนจะเชื่อแล้วหยิบตามสี
(กฎเต็มอยู่ในสกิล **`medical-data-safety`**)

## 27. ก้อนในบรรทัดชื่อยาห้ามถูกตัดขาดกลาง 🟠

### ปัญหา

```
Trimethoprim Sulfamethoxazole (Co-trimoxazole) (SMX-TMP) (40 + 200
mg/5 mL) suspension
```

`(40 + 200` ค้างบรรทัดบน `mg/5 mL)` ตกบรรทัดล่าง — อ่านแล้วสับสนว่าความแรงเท่าไหร่กันแน่

### วิธีแก้

ห่อแต่ละก้อน (ตัวย่อ · ความแรง · % · รูปแบบ · ER/IR · ชื่อการค้า) ด้วย `white-space:nowrap`
โดย**วางเว้นวรรคไว้นอก `<span>`** จึงยังขึ้นบรรทัดใหม่ระหว่างก้อนได้ตามปกติ

```jsx
// ME-DRP — เว้นวรรคเป็นข้อความ ต้องแยกออกมานอก span
const part = (style, node) => (
  <>{" "}<span style={css(style + "white-space:nowrap;")}>{node}</span></>
);

// ยาคืน — เว้นวรรคทำด้วย margin-left อยู่แล้ว ใส่ nowrap ได้เลย
const nw = (on) => (on ? { whiteSpace: 'nowrap' } : null);
```

🚨 **ก้อนที่ยาวเกินกรอบต้องยอมให้ตัด** ไม่งั้นล้นออกนอกจอมือถือ
เว็บยาคืนตั้งเกณฑ์ที่ **26 ตัวอักษร** (ยาวสุดในคลังคือความแรง 42 ตัวอักษร
`25 + 2 + 5000 mcg/1 mL + mg/1 mL + IU/1 mL` → ปล่อยตัด)

กล่องนอกใช้ `overflow-wrap:anywhere` · **ห้ามใช้ `nowrap` + `ellipsis` กับทั้งบรรทัด**
(ความแรงกับชื่อการค้าจะโดนตัดหาย — ดูข้อ 2)

## 🔴 อย่าเดาชิ้นส่วนของชื่อยาจากการอ่านข้อความ — ให้ส่งข้อมูลดิบรายช่องมา

**ต้นเหตุจริง** — ตัวแยกชื่อยาเดาว่าตรงไหนคือชื่อ ตรงไหนคือความแรง จากการอ่านข้อความทั้งก้อน
**พอสูตรการประกอบชื่อเปลี่ยน ตัวเดาก็เดาผิดทันที** แล้วสีของแต่ละส่วนสลับกันทั้งเว็บ

```js
// ❌ ส่งชื่อที่ประกอบเสร็จแล้วไปให้ตัววาดเดาเอง
<DrugName text="Enalapril 5 mg tab" />

// ✅ ส่งข้อมูลดิบรายช่อง แล้ววาดทีละส่วน
<DrugName generic="Enalapril" strength="5 mg" form="tab" />
```

🚨 **ตัววาดต้องได้ข้อมูลดิบเสมอ** การเดาจากข้อความใช้ได้เฉพาะกับข้อมูลเก่าที่เก็บไว้เป็นข้อความแล้วเท่านั้น
