# แผนรอบสอง ร่องรอย (Remnant) · ตรวจทาน 3 เอเจนต์ + ขยายโลก 3 × 3 กม. ละเอียดขึ้น สมจริงขึ้น

## Context
เดโม 0.1.0 ครบ 12 ช่วงแล้ว (พุช `6f940dc` `37a6c0c`) · แผนรอบแรกเก็บอยู่ที่ `docs/PLAN.md`
พี่กันสั่งรอบนี้ (ยกคำพูดตรง ๆ)
- *"ตรวจทานอีก 1 รอบ รัน 3 เอเจ้นหาข้อบกพร่อง"*
- *"ป่าเราขอใหญ่กว่านี้ หนาแน่น มีระบบนิเวศ"*
- *"เมืองขอให้คิดว่าเมืองนั้นมีจริง สามารถเดินเข้าสำรวจตึกได้"*
- *"สัดส่วนของจริง ให้มนุษย์หมึกสูง 1.5 เมตร"*
- *"โมเดลเพิ่มความละเอียดกว่านี้ ทุกอย่างขอละเอียดระดับนึง เพราะเดี๋ยวเราใช้คอมแรงกว่านี้เทส"*

- *"เพิ่มความหลากหลายของต้นไม้ สัก 15-20 ชนิด บางต้นมีต้นที่ตาย บางต้นมีดอก มีผล"* · *"ดอกไม้เพิ่มชนิด"*
- *"เพิ่มอารยธรรมของมนุษย์ที่โดนป่ากลืนกิน"* · *"ในถ้ำต้องมีความน่าสนใจ มอสเอย"*

ผลที่อยากได้ โลกกว้าง 3 × 3 กม. (เดินข้ามราว 33 นาทีที่ความเร็วเดิน 1.5 ม./วิ ตรงกับภาพแรกของพี่กัน "เดินข้ามสัก 30 นาที") ทุกอย่างขนาดเท่าของจริงเทียบกับเอเลี่ยนสูง 1.5 ม. ป่าหลายแบบที่มีชีวิต ร่องรอยมนุษย์ถูกป่ากลืน ภาพละเอียดพอให้คอมแรงดูสวย แต่เครื่องนี้ยังเปิดทดสอบได้

## ผังแมพ 3 × 3 กม. (กึ่งกลาง 0,0 · ขอบ ±1500)
```
 เหนือ   ▲▲▲▲ เทือกเขาสูง ยอดหิมะ หน้าผา ลานหินร่วง ทุ่งหญ้าบนเขา · ถ้ำหินปูน ▲▲▲▲
          ป่าสนต้นสูงมาก (ตีนเขา)        │แม่น้ำจากเขา│   ป่าผสมผลัดใบ
 ตะวันตก  ป่าใหญ่ทึบ · หมู่บ้านกลางป่า    │ไหลลงใต้   │   เนินคลื่น ทุ่งดอกไม้
          ทางรถไฟร้าง · ถ้ำเหมืองเก่า      │ป่าดิบชื้นใน│   ทุ่งหญ้าสูง
          ป่าที่เคยเป็นไร่ (แถวต้นไม้)      │หุบลึกริมน้ำ│
          ━━━━━━━━━━ ถนนหลวงตะวันตก–ตะวันออก ━ สะพานพัง ━━━━━━━━━━━
          ทุ่งจอดยาน (ชายป่า)   เมืองในหุบเขาริมแม่น้ำ + ไร่นารอบเมือง
 ใต้                                        ทะเลสาบ ที่ลุ่มน้ำ ต้นกก
```
ยานห่างเมืองราว 1 กม. · ป่าดิบชื้นอยู่ในหุบลึกริมแม่น้ำที่อุ่นและชื้นกว่าที่อื่น (มีน้ำตก) ให้อยู่ในโลกเดียวกับภูเขาหิมะได้อย่างมีเหตุผล

## ป่า 5 แบบ
| ป่า | หน้าตา |
|---|---|
| ป่าสนต้นสูงมาก | สนยักษ์เรดวูดสูงลิ่ว ลำต้นใหญ่ พื้นป่าโล่ง เฟิร์น ใบสนร่วงหนา แสงลอดเป็นลำ |
| ป่าดิบชื้น | หลายชั้น ไม้โผล่เรือนยอด ไทรรากอากาศรัดต้นอื่น เถาวัลย์ ปาล์ม เฟินต้น กอไผ่ กล้วยไม้ มอสทุกพื้นผิว น้ำตก มืดชื้น |
| ป่าผสมผลัดใบ | โอ๊ก เบิร์ช เมเปิล บีช ใบหลายสี ทุ่งโล่งแทรก |
| ป่าที่เคยเป็นไร่ (พี่กันเลือกแบบ ก.) | ต้นไม้ยังเรียงเป็นแถวตามแนวปลูกเดิม สวนแอปเปิลกับมะม่วงที่ปล่อยร้าง สวนสนปลูกแถวตรง ไม้ป่าขึ้นแทรก รั้วพัง รถไถสนิมเขรอะ คูน้ำ ยุ้งฉางพัง (เข้าได้) |
| ป่าทึบทั่วไป | ป่าผสมสนกับไม้ใบกว้าง ชั้นไม้พุ่ม ขอนไม้ล้ม ตอไม้ ต้นตายยืนต้น |
ทุกป่ามี **ขอนไม้ล้ม** (มีมอส เห็ด บางท่อนกลวง บางต้นล้มทั้งราก) · **ต้นตายยืนต้น** · **ซากรถในป่า**
