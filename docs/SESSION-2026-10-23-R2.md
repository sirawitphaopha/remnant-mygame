**ปากถ้ำกับหน้าผาตอนนี้เป็นยังไง ทำไม** (ภาพ `docs/test-shots/r2-11/02-mouth-after-fix.jpg`)
- หน้าผาหลังปากถ้ำเป็นแค่ก้อนเนินโค้งเรียบ: `src/world/terrainGen.ts` ฟังก์ชัน `shape` ดันพื้นขึ้นราว 22 ม. ภายในระยะราว 6 ม. (`rise`) เติมความขรุขระแค่ราว 3 ม. (`detail.noise` ขนาดคลื่น 9 ม.) ออกมาเป็นกำแพงเทาเรียบ
- ปากถ้ำคือรูที่เจาะผ่านผิวเนินนั้น (`Caves.cutTerrain`) ข้างในมีท่ออุโมงค์ยื่นออกมา 1 ม. ขอบรูหยักตามตารางพื้น ไม่ใช่ขอบหินจริง
- รอบปากถ้ำไม่มีหินเลย เพราะห้ามหินกับต้นไม้ขึ้นในระยะ 14 ม. รอบปากถ้ำ (`canPlace` ใน `src/world/scatter.ts`) และบนเนินเหนืออุโมงค์ (`overCave` ช่วง 11) บริเวณนี้จึงโล่งที่สุดในแมพ
- ปากถ้ำจริง: ชะง่อนหินยื่นคลุมปาก ปากกว้างต่ำ รูปไม่สม่ำเสมอ กองหินที่หล่นอยู่หน้าถ้ำ รากไม้กับมอสห้อยจากขอบ หน้าผาเป็นชั้นหินมีขอบมีชั้น

**ภูเขาเรียบเพราะอะไร**
- พื้นทั้งแมพเก็บความสูงเป็นตารางทุก 2 ม. หนึ่งจุดมีความสูงค่าเดียว จึงทำหน้าผาตั้งฉาก ชะง่อนยื่น ชั้นหินไม่ได้ ลาดชันออกมาเป็นแผ่นเอียงยืด
- ความขรุขระของภูเขาเป็นคลื่นใหญ่ รายละเอียดเล็กมีน้อย
- ตรงที่ชัน (`src/render/TerrainMesh.ts` `rock`) แค่เปลี่ยนสีเป็นสีหิน ไม่มีรูปทรงหินบนผิว · ลายพื้นผิวเป็นลายดิน (`applyDetail(..., 'soil')`) ยืดเป็นริ้วบนลาดชัน และจางหายตั้งแต่ระยะ 40 ถึง 140 ม. ภูเขาไกลจึงเรียบสนิท
- ภาพทดสอบถ่ายตอนเที่ยง แดดอยู่บนหัว เงาบนผิวน้อย ยิ่งดูแบน

**ข้างในถ้ำหินปูนตอนนี้ vs ของจริง**
- ตอนนี้ (`src/world/caves.ts` `buildCaves` · `src/render/Caves.ts`): ท่อเส้นเดียว กว้างเกือบเท่ากันตลอด คดนิดหน่อย พื้นแบนเรียบ ลาดลงสม่ำเสมอ มีห้องกว้างขึ้นแค่ 3 จุด ดูเหมือนท่อระบายน้ำ
- ของจริง: น้ำละลายหินตามรอยแตกกับรอยต่อชั้นหิน ทางเดินเป็นช่วงตรงแล้วหักมุม แตกกิ่ง มีทางตัน · รูปตัดเปลี่ยนตลอด (ช่วงที่เกิดตอนจมน้ำกลมรีคล้ายท่อ · ช่วงที่น้ำกัดพื้นเป็นร่องสูงแคบ · ทรงรูกุญแจ · เพดานต่ำต้องก้มหรือคลาน) · ห้องโถงใหญ่เกิดจากเพดานถล่ม พื้นเป็นกองหินก้อนใหญ่ · พื้นมีขั้น หลุม หินถล่ม แผ่นหินปูนเคลือบ แอ่งน้ำขังเป็นขั้นบันได · หินย้อยขึ้นเป็นแนวตามรอยแตกบนเพดาน
- ถ้ำเหมือง: อุโมงค์เหลี่ยมกว้างเท่ากันใกล้ของจริงแล้ว (คนขุด) แต่ยังขาดทางแยกด้านข้างกับปล่องแนวตั้ง

**ทางแก้ที่แคลร์เสนอ (ยังไม่ได้ทำ)**
- ปากถ้ำกับหน้าผาปั้นเป็นโมเดลหินแยกจากพื้น (แบบเดียวกับ `src/render/models/rocks.ts`) มีชะง่อนคลุมปาก ชั้นหิน กองหินหน้าถ้ำ รากไม้กับมอสห้อย · ต้องใส่ตัวชนให้ตรงกับโมเดล (`Structures` หรือ `CircleColliders`)
- ลาดชันบนภูเขาวางหินโผล่กับชั้นหินจริง ใช้ลายหินแทนลายดิน · เพิ่มรายละเอียดเล็กของภูเขาให้มีสันมีร่อง
- ถ้ำหินปูนสร้างใหม่: แนวทางเป็นช่วงตรงหักมุมตามรอยแตก มีทางแยกกับทางตัน รูปตัดหลายแบบ ห้องถล่ม พื้นไม่เรียบ หินย้อยเรียงตามรอยแตก · เหมืองเพิ่มทางแยกกับปล่อง
- ต้องแก้ตามไปด้วย: `caveAt` ตอนนี้คิดว่าถ้ำเป็นเส้นเดียว ต้องรองรับทางแยกกับพื้นสูงต่ำ · เทส `tests/caves.test.ts` (เดินถึงปลายถ้ำ ผนังกัน กล้องอยู่ในโพรง) ต้องผ่านเหมือนเดิม · เล่นทดสอบในโครมของพี่กัน (ทำบนเครื่องคลาวด์ได้แค่โค้ดกับเทส)

## สิ่งที่ต้องรู้ก่อนทำงานต่อ
1. อ่าน `CLAUDE.md` → `docs/PLAN-R2.md` → `docs/phases-r2/TECH.md` → รายงานช่วงล่าสุด `docs/phases-r2/phase-11.md` → `docs/BUGHUNT-2026-10-23.md` (ข้อที่ย้ายไปช่วง 12 ถึง 14)
2. ทุกช่วง `npm run typecheck && npm test && npm run build` ผ่าน → เล่นทดสอบในโครมของพี่กัน → ภาพ `docs/test-shots/r2-XX/` → รายงาน `docs/phases-r2/phase-XX.md` → แก้รายงานตรวจ → commit ในเครื่อง
3. ตัวช่วยทดสอบในโครม: รอหน้าโหลดราว 17 วินาที กดเล่นต่อ `a.saveBlocked = true` `a.paused = true` ซ่อน `.overlay` · `a.teleport` วางตัวบนของที่สูงที่สุด ในถ้ำหรือในตึกให้ `a.player.place` แล้วตั้ง `a.player.y` เอง · กล้องตั้งเองแล้ว `a.renderer.render(a.scene, a.camera)`
4. แก้ไฟล์ด้วย python ในเครื่องนี้ ห้ามใส่ `\n` ในสตริงที่อยู่ใน heredoc (กลายเป็นขึ้นบรรทัดจริง โค้ดพัง · เจอซ้ำรอบนี้)

## กฎที่ใช้ตลอดรอบนี้
- ทุกข้อความถึงพี่กันเป็นภาษาไทย แทนตัวเองว่าแคลร์
- พุชเมื่อพี่กันพิมพ์ "พุช" เท่านั้น · เลขรุ่นเป็นของพี่กัน · ห้ามขึ้น Cloudflare
- เอเจนต์ที่พี่กันอนุมัติ 3 ตัว ใช้ไปครบแล้วในช่วง 0 ห้ามยิงเพิ่ม

- ห้ามแตะหน้าต่างโครมอื่นของพี่กัน (มีระบบโรงพยาบาลที่มีข้อมูลผู้ป่วย)

- โลกหลังมนุษย์หายไปราวพันปี ของใหม่ทุกชิ้นต้องผุพัง ป่ากลืน
